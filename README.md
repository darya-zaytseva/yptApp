📚 yptApp (Учебный трекер прогресса)
Профессиональное desktop-приложение для учёта учебного прогресса, управления расписанием, оценками и совместной учёбы. Создано на Java с современным графическим интерфейсом. Позволяет студентам и преподавателям организовывать учебный процесс, отслеживать успеваемость, управлять заданиями и мотивировать себя системой достижений.

🎯 О проекте
Почему был создан этот продукт?
yptApp появился как практическая реализация цифровой системы учёта учебного прогресса в формате локального desktop-приложения. Проект объединяет потребности студентов в планировании занятий, контроле заданий и анализе успеваемости с инструментами преподавателя для управления группами, расписанием и оценками. Разработка велась как комплексный пример полноценного корпоративного приложения с архитектурой MVC, реляционной базой данных и многооконным интерфейсом.

Какую проблему он решает?
Приложение предоставляет единую цифровую среду для организации учебного процесса без зависимости от облачных сервисов. Оно автоматизирует рутинные операции: ведение расписания, выставление оценок, загрузку материалов, отслеживание прогресса по предметам и учёт времени учёбы, заменяя разрозненные таблицы и бумажные планировщики структурированной системой.

В чём его ключевые преимущества?
Полная локальность и безопасность: Все данные хранятся в локальной базе MySQL на вашем компьютере
Ролевая система: Разграничение прав доступа для студентов и преподавателей
Комплексное управление учебным процессом: Группы, предметы, расписание, задания, оценки и материалы в одном приложении
Мотивация через геймификацию: Система достижений (бейджи) и визуальная статистика прогресса
Таймер учёбы: Встроенный трекер времени занятий с сохранением сессий и накопительной статистикой
Социальные функции: Добавление друзей, совместная учёба и мгновенные уведомления о событиях
Готовое рабочее решение: Полнофункциональное приложение с типовыми учебными сценариями «из коробки»

Технологии
Для работы приложения требуется:

Java Runtime Environment (JRE) 17 или выше: Скачать с официального сайта
СУБД MySQL 8.0 или выше: Скачать установщик
Архитектура проекта:

Язык и интерфейс: Java 17, JavaFX для современного GUI
База данных: MySQL 8.0 с полной схемой пользователей, групп, предметов, расписания, заданий и оценок
Архитектура: MVC (Model-View-Controller) с чётким разделением ответственности
Дополнительные компоненты: DAO-паттерн для доступа к данным, шифрование паролей (SHA-256), защита от SQL-инъекций (PreparedStatement)
Быстрая установка и запуск
Вы можете запустить приложение за несколько минут, используя готовые файлы:

Установите необходимое ПО:
Установите Java (JRE) по ссылке выше.
Установите MySQL Server. Во время установки запишите заданный вами пароль для пользователя root.
Настройте базу данных:
Скачайте готовый дамп базы данных.
Откройте командную строку MySQL (или общую командную строку/терминал).
Выполните команду для импорта данных, указав правильный путь к скачанному файлу. Вас попросят ввести пароль пользователя root MySQL.
Запустите приложение:
Скачайте приложение из репозитория.
Запустите его двойным кликом или из командной строки.
Важно: Перед запуском убедитесь, что сервис MySQL Server запущен в вашей системе.

Возможности
yptApp предоставляет полный цикл управления учебным процессом:

👤 Система пользователей: Регистрация и авторизация с ролями student и teacher, изоляция данных по группам
🏫 Управление группами: Создание, редактирование и удаление учебных групп с указанием специальности, курса и приватности
🎓 Управление студентами: Создание карточек студентов с ФИО, датой рождения, контактами и привязкой к группе
📖 Управление предметами: Создание дисциплин с кодом и учебными часами
📅 Расписание занятий: Привязка предметов к группам по дням недели и парам с указанием аудиторий
✅ Задания и оценки: Создание заданий с дедлайнами и максимальным баллом, выставление оценок с комментариями
📁 Учебные материалы: Загрузка и просмотр файлов по предметам
📆 Календарь: Недельная сетка занятий с цветовой маркировкой и навигацией
⏱️ Таймер учёбы: Выбор предмета, отсчёт времени, сохранение сессий и обновление статистики
📈 Прогресс и аналитика: Визуализация часов, заданий и среднего балла по предметам (круговые диаграммы)
🏆 Система достижений: Автоматическая выдача бейджей за успехи в учёбе
👥 Друзья и совместная учёба: Отправка запросов в друзья, совместная мотивация
🔔 Уведомления: Мгновенные оповещения о событиях с индикатором непрочитанных
📊 Личная статистика: Общее время учёбы, количество сессий, интересы, цели и уровень
🔍 Поиск: Поиск групп и напарников для совместной учёбы

Использование
Начало работы: При первом запуске зарегистрируйтесь как student или teacher, или войдите под существующими данными
Главный экран: После входа откроется рабочее пространство с доступом к расписанию, предметам, заданиям и статистике
Основные функции (панель инструментов):
Группы: Создание и управление учебными группами, вступление в группы
Предметы: Управление дисциплинами, загрузка материалов
Расписание: Просмотр календаря на неделю и на сегодня
Задания: Создание и отслеживание учебных заданий с дедлайнами
Оценки: Выставление и просмотр успеваемости
Таймер: Запуск сессии учёбы по выбранному предмету
Друзья: Управление учебными связями и совместная мотивация
Профиль: Редактирование личных данных, просмотр достижений и статистики
Работа с данными:
Двойной клик по карточке студента, предмета или задания открывает детальное редактирование
Все изменения сохраняются автоматически через транзакции БД
Фильтрация расписания по текущему дню недели для быстрого доступа

Разработка и тестирование
Проект построен на архитектуре MVC с чётким разделением:

Модели: User, Student, Group, Subject, Schedule, Task, Grade, Material, Achievement, Friend и др.
Контроллеры: MainController, LoginController, ScheduleController, TaskController и другие для каждого окна
Представления: FXML-файлы с современным UI
DAO-слой: Отдельные классы для работы с каждой сущностью в БД
